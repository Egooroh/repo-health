# Проверка переносимого запуска

Дата: 17 сентября 2026 года.

## Выполнено

- Реальный запуск через Windows PowerShell 5.1 из копии исходников без готового бинарного файла, с пробелами в пути и из посторонней рабочей папки.
- Сборка текущего проекта, отдельный выбранный порт, успешные `/healthz` и `/api/v1/meta`, запуск без токена.
- База создана в тестовой копии; пользовательская база не использовалась.
- Повторный запуск на занятом порту завершился с кодом 1; предыдущий тестовый сервер остался доступен.
- Скрипты PowerShell проходят синтаксическую проверку; Bash проходит `bash -n` в Git Bash.
- `docker compose config --quiet` проходит. Недоступный Docker завершается с кодом 1 и пояснением.
- `go test ./...`, `go vet ./...`, `node --check web/app.js` проходят.

## Ограничения

Docker установлен, но его служба не запущена: сборка образа и запуск контейнера не проверены. Реальный запуск на Linux/macOS не проверен; для Bash проверен синтаксис. Ввод действующего PAT и живой анализ SourceCraft в этом прогоне не выполнялись.

Go либо Docker с Compose нужно установить на каждом компьютере. Работа без зависимостей, сетевого доступа при первом скачивании и соблюдения локальных политик безопасности не гарантируется. Переход между Go и Docker использует разные хранилища данных.
