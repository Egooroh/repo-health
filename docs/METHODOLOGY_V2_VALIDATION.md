## Проверяемые свойства

Тесты проверяют счётчики и шкалы категорий, неизвестные состояния и неполноту внутри категорий, минимальные выборки, пустые когорты, выход за диапазон и неконечные числа, порог полноты 60%, минимум трёх достаточно измеренных категорий, границу свежести 24 часа, запрет публичного расчёта приватного репозитория, независимость публичного вывода от Security, дедупликацию и конфликты AppSec, accepted/resolved/false_positive, сохранение неопределённости после потери доступа к ранее ограниченному Security, снятие ограничения свежим полным результатом.

Перебор проверяет, что увеличение каждого измеренного балла категории от 0 до 100 не снижает общий результат; увеличение дублирования не выводит Code за диапазон; добавление находок не повышает Security; исправление находки не снижает Security. Повторный расчёт одного снимка и перестановка находок сохраняют результат.

Исходные контрпримеры: формула Issues из PDF даёт 4030; добавление TODO повышает исходный Code с 48 до 75; ограничение только категории Security допускает общий Score 86. Эти числа воспроизведены. Новый расчёт Issues соблюдает шкалу; TODO исключён из входов балла; ограничение применяется к итоговому личному Score.

## Границы проверки

Все данные синтетические. Тесты не проверяют живой SourceCraft/AppSec, роль пользователя, реальную полноту пагинации, парсинг README или кода, привязку отчёта к ревизии, историю изменения прав и сохранение исторического ограничения в БД. Эти условия заданы спецификацией и остаются задачами адаптеров/сервисов.

Калибровка порогов и весов на реальных проектах, сравнение типов репозиториев и проверка чувствительности рейтинга ещё не выполнены. Тесты арифметической монотонности не доказывают, что все способы изменения реального кода устойчивы к накрутке. Версия не подключена к работающему HTTP-приложению и не меняет пользовательские данные.
